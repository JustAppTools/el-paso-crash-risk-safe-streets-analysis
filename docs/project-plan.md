# Project Plan

This repository presents the project as work completed during a September-December 2025 portfolio period. The data itself does not need to be limited to that period.

## Phase 1: Scoping

- Define project question and study area.
- Confirm data availability from TxDOT, City of El Paso, and El Paso MPO.
- Document source links, limitations, and privacy considerations.

## Phase 2: Data Acquisition

- Use the public Vision Zero collision layer for dashboard mapping and aggregate crash summaries.
- Optionally request or export public crash data from TxDOT CRIS for deeper local ArcGIS Pro analysis.
- Download City of El Paso feature layers for streets, bus stops, routes, bike lanes, schools, and parks.
- Collect MPO maps or shapefiles for regional/equity context.
- Add Census ACS variables if equity analysis is included.

## Phase 3: Data Cleaning

- Reproject layers.
- Remove unusable crash records.
- Classify severity and vulnerable-road-user categories.
- Snap or associate crashes with road segments and intersections.

## Phase 4: Analysis

- Map crash density and statistically significant hot spots.
- Identify corridors and intersections with high KSI and vulnerable-road-user risk.
- Score candidate priority zones using crash severity and exposure context.
- Compare findings with published Vision Zero High Injury Network maps.

## Phase 5: Cartography and Delivery

- Design final maps in ArcGIS Pro.
- Prepare summary charts and source notes.
- Export final screenshots or layout images.
- Publish a concise README narrative and optional ArcGIS StoryMap/Dashboard link.

## Candidate Final Title

El Paso Crash Risk & Safe Streets Analysis

## Candidate Repository Description

ArcGIS project analyzing El Paso crash risk, high-injury corridors, vulnerable road-user hotspots, and safe-streets priority areas using public transportation and safety data.
