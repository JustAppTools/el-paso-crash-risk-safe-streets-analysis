# CRIS-Derived Aggregate Outputs

This folder is reserved for public, aggregate crash-summary tables generated by:

```powershell
python scripts/build_cris_derived_summaries.py
```

The script uses the public El Paso Vision Zero collision layer without geometry and writes summary tables only. It does not store raw crash records, coordinates, crash IDs, case IDs, or crash-report details.

If the CSV and metadata files are absent, rerun the script when the public ArcGIS service is reachable.
